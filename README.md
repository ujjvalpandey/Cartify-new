🛒 Cartify – E-commerce Frontend (MERN)

Cartify is a modern and responsive e-commerce frontend application built using the MERN stack. It provides a seamless shopping experience with clean UI, efficient state management, and scalable architecture.

🚀 Features

- 🛍️ Browse products with dynamic listing
- 🔍 Search and filter functionality
- 🛒 Add to cart & manage cart items
- 👤 User authentication (Clerk integration)
- 📱 Fully responsive design
- ⚡ Fast performance with Vite

🧰 Tech Stack

- Frontend: React.js, Vite
- State Management: Context API
- Routing: React Router
- Authentication: Clerk
- Icons & UI: React Icons, Lucide

📂 Project Structure

src/
├── components/
├── pages/
├── context/
├── assets/

⚙️ Installation

npm install
npm run dev

🏗️ Build

npm run build

🌐 Deployment

This project can be deployed on platforms like Vercel, Netlify, or Render.
